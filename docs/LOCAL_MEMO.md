# クイックメモ

参照：[Local Memo](https://maruyamamasaya.github.io/tool/local-memo/)。ブラウザ版の機能をSwiftUIの独立windowとして追加。

## 実装仕様

- テキスト・CSVカテゴリの「クイックメモ」。ToolID・保存先を維持し、旧名「ローカルメモ」でも検索可能。
- 複数メモの追加・選択・本文編集。タイトル入力と保存ボタンは置かず、一覧は本文の先頭行で表示（空本文では既存タイトル／新しいメモ）。新規作成順で、入力中に一覧が並べ替わらない。履歴・JSON・削除は操作メニューに集約。
- 編集ごとに同期的にローカルJSONをatomic保存。保存失敗は画面へ表示し、再保存に成功するまでwindow／アプリ終了を許可しない。JSON退避も可能。
- 保存先：`~/Library/Application Support/MyToolBox/LocalMemo/memo-v1.json`。本文は暗号化しない。外部通信なし。
- 最新5世代のスナップショット。編集時は最短60秒ごと、追加で記録。削除・復元前は操作前の全メモを記録。復元は確認付きで全メモを置換。
- JSON書き出しはWeb版と同じ`version/exportedAt/notes`。Web版の書き出し・メモ配列を読込可能。ID重複・日時不正・必須フィールド欠落は拒否。20 MiBを超える読込を拒否。
- 既存の保存ファイルを読み込めない場合は元ファイルを保持し、編集を無効化。再読み込みボタンで復旧を試せる。
- ブラウザのlocalStorageは自動移行しない。Web版からJSONを書き出し、この画面で復元する。

## 編集画面

Windowsのメモ帳程度のシンプルな本文中心の画面。メモ一覧は初期非表示、左上で開閉し本文／先頭行を検索できる。新規は⌘N、本文検索は⌘F。NSTextViewによるプレーンテキスト編集でUndo／Redo・選択・コピー／貼付けを利用でき、メモ切替時はUndoをリセットして別メモへの混入を防ぐ。

表示設定で文字サイズ11〜28・折り返しを変更しローカル保存する。操作メニューからUTF-8テキストを別メモとして読み込み（⌘O、20 MiB以下）、選択メモを.txtへ書き出せる（⇧⌘S）。読み込んだメモもアプリ内で自動保存し、元の外部ファイルは書き換えない。

同じ表示設定内で、⌃⌥⌘＋英字のグローバルショートカットを設定可能（初期OFF、候補M）。カレンダーと設定・イベントIDを分離し、競合時はエラー表示。Mac標準のfn＋Qは使用しない。
