# 比較ツール

2026-10-15。青い比較アイコンにテキスト差分とリスト比較を統合。入力はローカルメモリ内で処理し、通信・自動保存なし。コピーは明示操作。

## 原本と実装

原本は[GitHubのtoolリポジトリ](https://github.com/maruyamamasaya/tool)のdiff-viewerとlist-compare。確認revisionはc011a4aa3518af8c72686ed3cf6950363b3612d7。ライセンスを特定できなかったため、挙動を確認して独立したSwift実装とし、ソース・素材は同梱しない。

## テキスト差分

- 改行コードをLFへ正規化。空入力は0行、空行・末尾改行は区別する。
- LCSで同一行を対応付け、変更ブロックは共通の前後文字と単語の類似度で対応付ける。変更行の組合せは推定で、意味解析ではない。
- 同一/変更/削除/追加の件数、左右の元行番号、削除側の赤・追加側の緑、語の変更箇所を表示。Unicodeの書記素境界からUTF-16強調範囲を計算する。Swiftの文字列比較は正規等価なUnicode表現を同一視する。
- 折返し切替、左右入替、クリア、比較結果コピー。コピーは行頭の空白・-/+による読みやすいテキストで、適用可能なpatch形式ではない。
- 左右各256KiB・1,000行まで。原本の行数切捨てと異なり、超過はエラーとして部分結果を表示しない。約2秒の協調的予算を行処理の区切りで確認する。厳密な実時間上限ではない。

## リスト比較

1行を1項目とし、既定は前後空白を除去・空行を除外・大小文字を区別。3設定を変更可能。重複キーは最初の値にまとめる。共通とAのみはAの出現順・表記、BのみはBの出現順・表記を保持する。各列を個別コピーできる。件数は重複除去後。左右各1MiB・20,000行まで。入力変更は150ms待って直列actorで再計算する。

## 検証

Swift単体7件、Xcode Releaseビルド、署名確認。オフスクリーン描画は[evidenceの差分](../evidence/tool-text-comparison.png)と[リスト](../evidence/tool-list-comparison.png)。合成データであり監視の実測ではない。

実機のApplications内アプリで一覧12個目→比較ツールを開き、A=aaa/bbb/ccc/ddd、Bの3行目に空行追加で同一4・追加1、元行番号を確認。リストA=apple/banana/orange/apple、B=banana/orange/grapeで共通banana,orange・Aのみapple・Bのみgrape、A/B各3件を確認。左右入替後は片側結果が反転した。

全Unicode言語の照合、極端な長行の操作性、長時間の連続編集、全コピー操作は未検証。入力内容や設定の終了後復元、ファイル直接比較、patch生成は未対応。
