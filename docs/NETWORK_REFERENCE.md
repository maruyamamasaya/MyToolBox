# ポート番号検索・HTTPステータス一覧

参照：[Port Number Finder](https://maruyamamasaya.github.io/tool/port-number-finder/)、[HTTP Status Viewer](https://maruyamamasaya.github.io/tool/http-status-viewer/)。2026-10-15に公開JavaScriptの収録データと検索仕様を確認し、ネイティブUIへ移植。

## 実装

- システム・音声カテゴリに独立した2ツールを追加。既存のカテゴリ・検索・お気に入り・window再利用に対応。
- ポート43件。数字のみの入力は番号完全一致、それ以外はサービス名・用途の部分一致。前後空白除去、大文字小文字を区別しない。データベースは`database`／`db`でも検索。
- TCP／UDPフィルター。TCP/UDP併記はどちらでも表示。よく使う8ポートのボタンはフィルターを解除して対象番号を表示。
- HTTPステータス52件。コード・英語名・日本語説明・分類の部分一致、1xx〜5xxフィルター。
- 双方に検索クリア、結果件数、0件表示、番号／説明ごとのコピー。3テーマは共通ToolPageを利用。
- データはSwift定数として同梱。網羅的な登録一覧ではなく、参照Web版の主要項目。用途や説明は参照版に準じる。
- ツール実行時の外部通信・接続確認・ポートスキャンなし。入力や結果の永続化なし。
