# 時間ツール

参照：[ポモドーロ](https://maruyamamasaya.github.io/tool/pomodoro-timer/)、[Timer Board](https://maruyamamasaya.github.io/tool/timer-board/)、[時間計算](https://maruyamamasaya.github.io/tool/time-calculator/)、[会議タイマー](https://maruyamamasaya.github.io/tool/meeting-timer/)。Webページの画面を確認し、ネイティブUIで実装。実行時の外部通信なし。

一覧の「日付・予定」から4つの独立ツールとして起動。共通テーマ・お気に入り・検索に対応。

## ポモドーロタイマー

作業25分／休憩5分が初期値。「時間を設定」で作業1〜180分、休憩1〜60分を適用。設定はローカル保存。開始・一時停止・再開・リセット。作業完了で今日の回数を加算し休憩へ、休憩完了で作業へ切り替える。次区間は手動開始。日付はMacのローカル日付、完了を検出した日に記録。ウィンドウを閉じると計測終了、回数と設定は保持。

## タイマーボード

最大12個。名前・カウントダウン／ストップウォッチ・時分秒・メモを設定。開始／一時停止、個別リセット、全一時停止、完了のみ／全リセット。設定内から複製・前後移動・削除。計測開始後のモード・時間変更はリセット後。0秒の開始不可。

設定と実行基準日時をUserDefaultsの`tools.timerBoard.v1`へ保存。スリープ中・アプリ終了中も実時間として計算、再起動後は復元。ウィンドウを閉じると全一時停止して保存。カウントダウンは終了時点で停止。通知は画面内のオレンジ表示と点滅、終了のみ／残り10秒・30秒・1分。動きを減らす設定では点滅なし。音・OS通知なし。

## 会議タイマー

15・30・45・60・90分を選択→開始の2操作。初期値30分なら開始だけ。時分秒の個別設定も可能。残り時間・進捗・実行中の終了予定を表示。一時停止・再開・リセットに対応。終了時は画面表示、終了時刻指定・予約開始は設けない。ウィンドウを閉じると計測終了。

## 時間計算

勤務時間：開始・終了・休憩を`HH:mm`で入力、実時間から休憩を差し引く。終了が開始より早ければ翌日、同時刻は0分。休憩超過・不正時刻はエラー。

複数行：1行1時間帯、`09:00 - 10:30`／`〜`／`～`／`–`区切り、空行を除く最大1000行。各行を独立して合計、重複時間帯も加算。結果は時間分・小数時間（小数2桁）・合計分。結果コピー・リセット。入力はウィンドウ内のみ。

## 検証状況

ユーザー指定でFast／Full・単体テスト実行・実機UI操作は後日まとめて実施。Xcode Release buildと署名確認は実装時に行う。TimeToolsTestsに日時ベースの一時停止／再開・復元・日付またぎ・入力エラーのケースを用意。

計測はDate差分のためシステム時刻変更の影響を受ける。スリープ中に画面更新・終了表示は行わず、復帰後に反映。バックグラウンドで確実に音や通知を出すアラームではない。

2026-10-20：計測する3ツールはそれぞれ同梱の独立プロセス。本体終了・再起動中も計測と操作を継続する。ツール自身を閉じる場合の停止仕様は従来どおり。時間計算は本体内のまま。[設計](../decisions/0011-independent-memo-timers.md)。
