# Git一括管理

Development直下の4本のGitスクリプトの操作をネイティブ画面へ統合。元スクリプトは変更せず、アプリ単体で動く。ネットワーク・サーバーカテゴリから開く。

## 操作

- フォルダを選択し「ローカル読込」。直下の通常ディレクトリのみ探索し、隠しディレクトリと.gitファイル型worktreeにも対応。シンボリックリンク先や孫階層は探索しない。選択フォルダだけUserDefaultsに保存する。
- ローカル読込は通信なし。originの同名ブランチの参照は最後のfetch時点であり、最新の同期確認ではない。
- 「状態確認（通信）」は選択したリポジトリのoriginをfetch/pruneし、変更ファイル・未送信・未取得と確認日時を表示。
- 「選択分を更新…」は確認ダイアログ後、未コミット・未送信がない対象だけff-onlyで更新する。
- 「コミット・送信…」は対象名とメッセージ・全変更を含む旨を確認後、git add -A、commit、fetchによる再確認、originの同名ブランチへのpushを実行する。未追跡・削除・既存ステージも含む。事前の変更一覧は折りたたみ表示。実行時点の変更が対象であり、レビュー後に他プロセスが編集した内容を固定するものではない。

## 停止と制約

Detached HEAD、初期コミットなし、originなし、同名リモートブランチなし、Git操作途中、リモート先行・分岐、認証・コマンド失敗で対象を停止し、残りを継続。強制push・reset・競合自動解消は行わない。失敗時はローカルコミットやステージ済み変更が残る場合がある。再実行前に状態確認する。

専用actorで順番に実行し、UIを占有しない。実行中は選択・重複実行・画面閉鎖を抑止する。各Gitコマンドは120秒上限。タイムアウトはロールバックではなく、既に反映された操作や子プロセスが残る可能性がある。状態を確認する。出力1MiB上限。表示はメモリのみ、一時出力は処理終了後削除。実行ログの永続保存なし。

認証は通常ユーザーの既存Git資格情報・SSH鍵／agentを使用。GUIから対話入力を求めず失敗表示する。SSHはBatchModeと接続15秒上限。既存Git設定のhooks・credential helperはGitの通常動作として実行される。スクリプトやシェル文字列を組み立てず引数配列で渡す。作業ディレクトリを変えるGIT_*環境変数は継承しない。初期フォルダはホーム下のDevelopment。

## 検証

GitBatchTestsは一時的なbare origin・2cloneを作り、チェック、dirty停止、コミット送信、リモート先行停止、ff更新、Detached HEAD、空リポジトリ失敗、メッセージ中のシェル文字の非実行を検証する。ユーザーのリモートへの送信は検証で行わない。`tools/RenderGitBatch.swift`で合成データの3テーマ描画を確認。実機のクリック操作は未検証。Full・Releaseビルド・署名検証成功。

## 独立プロセス（次回デプロイ用）

Git一括管理を同梱helperとして起動する実装を追加。本体終了・再起動では実行を止めず、対象フォルダ・選択・コミットメッセージ・一覧・処理結果をGit側モデルで維持する。起動済みツールの再選択は同じ画面へ戻る。選択フォルダの保存キーtools.gitBatch.rootを既存local.MyToolBoxドメインで引継ぐ。Git側の画面／アプリ終了は処理中に拒否し、操作前の更新／送信確認は維持する。テスト用確認境界を利用したローカルbare originとcloneだけの検証は[記録](../sessions/2026-10-20-independent-image-git.md)。本番未反映。

## 表示サイズ

標準480×600pt、最小460×520pt。拡大／小さく戻すで1100×850ptへ切替。フォルダ選択・ローカル読込は押下領域を確保したアイコンボタン。対象一覧だけスクロールし、選択・メッセージ・通信操作は上部へ保持。モデル、確認ダイアログ、処理中の終了拒否は共通で維持する。

初回読込は全件未選択。同じフォルダの再読込ではチェックとチェック解除を保持し、新しく見つかった項目は未選択。状態確認・取得更新・送信はいずれもチェックした対象だけに実行し、チェックなしでは実行しない。
