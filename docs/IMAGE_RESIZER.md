# 画像リサイズ

参照：[Web版](https://maruyamamasaya.github.io/tool/image-resizer/)。画像を選ぶ→寸法指定→プレビュー→別名保存の流れをmacOSネイティブで実装。SwiftUI＋ImageIO＋CoreGraphicsで完結し、Pythonや追加パッケージは不要。

## 操作

- ファイル選択または画像1枚をwindowにドロップ。
- 幅/高さを整数pxで指定。「縦横比を維持」は最後に編集した辺から反対側を四捨五入（最低1px）。ONへ戻すと幅を基準に補正。
- 25/50/75/100/200%は常に元画像を基準にする。
- PNGまたはJPEGを選択。元がJPEGなら初期値JPEG、それ以外はPNG。JPEG品質10〜100%、初期85%。
- 「リサイズする」でプレビュー・寸法・容量を表示。「画像を保存…」で保存先を選択。既定名は元名-幅x高さ.拡張子。
- 設定変更時は古い結果を消す。新しい画像の読込に失敗した場合も以前の画像/結果を残さない。

## 対応と上限

入力はJPEG/PNG/WebP/HEIC/HEIF/TIFF（OSのImageIOがデコードできるもの）、30MiB以下・4,000万画素以下。アニメーション/複数ページは拒否する。出力はJPEG/PNG、各辺1〜16,384pxかつ合計4,000万画素以内。Web版のWebP出力は実装せず、標準エンコーダーで安定して保存できる2形式に限定する。

高品質補間で拡大/縮小。縦横比OFFでは指定した縦横へ変形する。EXIFの向きを焼き込み、8bit sRGBで再描画。PNGは透明を保持、JPEGの透明部分は白背景。元のEXIF/GPS等のメタデータは転記しない。HDRや広色域の完全保持、容量の必ず縮小、拡大時の細部復元は保証しない。

入力を読取り、処理中はメモリで保持。明示保存だけ書込み、外部送信・自動保存なし。入力と同一パス・symlink・hardlinkへの保存を拒否する。別の既存ファイルを置換する場合は標準保存パネルが確認する。

## 検証

単体テストと合成画像による実ファイル往復・モデル動作・3テーマ描画を使用する。ファイルパネル/ドロップ等の実デスクトップ操作は自動描画と区別して記録する。
