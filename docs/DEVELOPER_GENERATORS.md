# ハッシュ・テストデータ生成

参照：[Hash Generator](https://maruyamamasaya.github.io/tool/hash-generator/)、[Dummy Data Generator](https://maruyamamasaya.github.io/tool/dummy-data-generator/)、[UUID Generator](https://maruyamamasaya.github.io/tool/uuid-generator/)、[Text Generator](https://maruyamamasaya.github.io/tool/text-generator/)。2026-10-15にHTML／JavaScriptの機能・制約を確認。

## 統合方針と実装

- 「ハッシュ生成」と「テストデータ生成」の2入口をテキスト・CSVカテゴリへ追加。
- ダミーデータ／テキスト／UUIDの重複をテストデータ生成の4モードに統合。検索は元の英語名・UUID・ダミーデータ・テキスト生成にも対応。
- 既存の連番テキスト生成は入力行への番号付与なので独立のまま。CSVビューワー／エディターはファイルの閲覧・編集なので独立のまま。CSV生成の引用処理は既存CSVDocument.serializeを共有。
- ハッシュ：CryptoKitのSHA-1／256／384／512、HEX小文字／Base64。UTF-8の生バイトを使用し、空白・改行を正規化しない。空文字にも対応。入力上限1MiB。
- 文章：1〜10文章、短文／通常文／長文、日本語／英語／日本語＋英数字。
- 文字列：日本語／英語／英数字／数字／英字／記号入り／メール風／URL風／IP風／ファイル名風。1件1〜10,000文字、1〜1,000件、合計100万文字・出力4MiB以内。改行／カンマ／空白／タブ区切り。
- 文字列モードは参照版と同様に指定文字数へ切り詰め・連結するため、構造化形式の妥当性は保証しない。UUID風はUUIDモードへ集約し、完全なUUID v4を1〜100個生成。個別／全文コピー。
- CSV：1〜10列・1〜10行。列名と10型（Number/Text/Name/Email/Date/Boolean/Status/Prefecture/Price/ID）。列名は1,024バイト以内、空ならcolumn_N。ヘッダーとカンマ・引用符・改行のエスケープ付き。
- メール／URLはexample.com、IPは文書用192.0.2.0/24を使う。日付は2024〜2026年。データ内容はローカルのサンプル語から生成。
- 専用actorで計算、設定変更時に旧Task／結果を無効化。画面を閉じると処理を取り消す。入力・生成結果の永続化／外部通信なし。
