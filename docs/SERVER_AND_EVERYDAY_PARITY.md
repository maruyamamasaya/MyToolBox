## 意図して残した差

- ネイティブ共通UIへ統合するため、画面配置・タブ/同時表示・コピー文面は同一ではない。Web版のテーマ切替は共通3テーマで代替。
- 辞典はコマンド名・カテゴリのカバレッジを揃え、説明・例・オプション説明は独自記述。参照の汎用オプションの一括転用はしていない。関連リンクも同カテゴリから独自選定。
- 通貨の初期レートは空欄。参照の例示150を現在の実レートとして扱わない。手入力後の換算/入替は可能。
- CIDR/集計/ツリー等の入力件数・容量、電卓の式長/深さ上限を保持。ツリーの名前は255文字以内、/・制御文字は拒否。過大入力・曖昧入力を無制限に受け付けない。
- ツリーの旧平坦JSONは安定UUIDでローカル保存し、交換用は参照と同じ入れ子JSONを出力。参照JSON読込ではUUIDを再作成する（参照側もIDを再作成）。カスタム記号の任意テキストを完全復元する専用パーサは双方とも持たない。
- Unixは秒/ミリ秒を明示指定可能。自動判定には参照同様の曖昧さがあるので、遠い過去/未来の秒値は明示指定を使う。数値/日時の対応範囲と丸めは現行仕様に従う。
- 参照の挙動上の問題を再現する目的ではない。Cronの日/曜日のOR説明、DNS TXTのバイト分割・IP検証、絶対零度未満拒否等は現行の検証を維持。
