# 機能一覧・既知の制約

| 機能 | 実装 | 検証 |
| --- | --- | --- |
| CPU全体・P/E・各コア・コア数 | 実装 | M1 Maxで取得成功。対応は動的トポロジー |
| GPU全体使用率・名称・統合メモリ | 実装 | IOAccelerator読取成功。複数GPU未対応 |
| RAM容量・空き・キャッシュ・圧縮・pressure・swap | 実装 | 実機取得。使用量は推定 |
| IF状態・送受信速度・累積 | 実装 | 主IF取得。IF切替はロジックテスト、実配線切替は未検証 |
| APFS Data容量・Disk I/O | 実装 | 実機取得。I/Oは物理／仮想の論理合計 |
| Battery残量・電源・充電・健康・cycle | 実装 | 実機取得 |
| Battery最大容量・設計容量 | 推定として実装 | 生値取得、mAh換算・校正は未検証 |
| Battery残り時間 | OS推定を実装 | AC使用中の取得不可のみ確認 |
| CPU全体/P/E・GPU温度、fan RPM | 実装 | M1 Maxで温度14点・ファン2基停止値取得。回転中と絶対精度は未検証 |
| Battery温度・電力 | 未対応 | 理由付き取得不可 |
| メニューバー2段数値・アイコン | 実装 | .app起動・常駐確認、目視未検証 |
| 7カテゴリ詳細・設定・終了 | 実装 | ビルド確認、UI操作未検証 |
| メニューバー表示切替・順序・compact | 実装 | 保存ロジック検証、UI未検証。詳細項目は常時利用可能 |
| 1/2/5秒間隔・Battery/Sensors別周期 | 実装 | コード・PoC確認。長期負荷未検証 |
| CPU/GPU/RAM/送受信の60秒グラフ | 実装 | 保持期間・欠損・時計変更を単体検証。描画未検証 |
| 単位・温度単位・設定UserDefaults保存 | 実装 | 独立suiteで往復・不正データ・補正テスト |
| ログイン起動UI・状態 | 実装 | 自動有効化なし。依頼による登録enabled確認、再ログイン未実施 |
| Sleep/wake・差分再取得 | 実装 | 差分resetテスト、実機sleep操作は未実施 |

アプリは外部依存パッケージ・外部通信コード・DB・テレメトリーを持たない。監視履歴はメモリ内の直近60秒のみ。設定はUserDefaultsへ、任意の定期ログはJSONLへ保存する。CLIのJSON保存は検証時に明示的に行う。

対象はmacOS 14以上のApple Silicon。今回の実証環境はmacOS 26.6.2 / M1 Maxのみ。Intel、別Apple Silicon、旧OS互換性を保証しない。Ad hoc署名のローカル実行用で、Developer ID署名・公証・App Store配布は未対応。

メニューバーが他アプリやノッチで狭い場合の自動縮小・退避は未対応。設定で項目を減らすかcompactを使用する。CPU/GPU温度はM1 Maxのみ対応、設定で華氏へ換算可能。60秒を超える履歴の画面可視化・通知・プロセス別内訳は未対応（定期ログの保存は可能）。[次段階の可視化案](VISUALIZATION_ROADMAP.md)に当日通信量等を整理。

測定の定義と根拠は[技術検証](TECHNICAL_VALIDATION.md)、移行判定は[チェックリスト](MIGRATION_CHECKLIST.md)を参照。

初期表示は参考画像に合わせてNetwork / CPU / RAM / SSD / BATの順。GPUも設定で表示可能。Sensorsは今回追加したCPU/GPU温度（CPU/GPU＋数値（温度アイコンなし）の1段表示）・FANの数値欄として初期表示。RAMは使用率%と横長RAMスティックの専用ベクターアイコン＋残り容量の1段表示（推定利用可能容量、小数2桁の10進GB）、SSDは空き容量を整数の10進GB（小数点以下切捨て、メニューのみ単位設定によらず固定）で表示。BATは充電中のみ雷マークを表示し、AC接続だけでは付けない。詳細画面では容量・状態も確認できる。

メニュー右側はFAN→RAM残り→CPU温度→GPU温度の固定順で集約。通常の2段項目は設定順。表示／非表示は従来のRAM・Sensors設定に従う。

クリックで390×620ptのtransientポップオーバーを表示。一覧カードから7詳細へ遷移し、戻る・設定・終了を同じ画面内で操作。初期カードは固定配置で、メニューバー非表示設定とは独立。メモリの重複しない内訳バー、温度履歴、当日通信集計は未実装。

定期ログ：主要7カテゴリをローカルJSONLへ時刻付き保存。10秒・7日で有効化、設定で停止・間隔・保存期間を変更可能。/Applications配置とログイン登録enabledを確認。再ログイン起動・長時間稼働は未検証。詳細は[運用](../OPERATIONS.md)。

ツール一覧：専用メニューアイコンから開く幅440pt・高さ可変（11個で628pt、最大680pt）の3列アイコン一覧。システムモニターと10のローカルツール（[初期5本](LOCAL_TOOLS.md)・[テキスト3本](TEXT_TOOLS.md)・[行/置換/リスト拡張](LINE_TOOLS.md)）を搭載。既存の数値メニューと監視・ログを維持し、モニター下端から一覧へ戻れる。
