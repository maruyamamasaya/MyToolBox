# ショートカット競合チェック

システム・音声カテゴリから開き、「Macをチェック」を押す。自動スキャン・入力監視・設定変更・外部送信・結果保存はしない。

## 取得範囲

- 起動中の通常／常駐アプリのメニューをアクセシビリティAPIで取得。権限がない場合は未確認を表示し、設定画面へのボタンを用意する。許可自体はユーザーが行う。
- macOSのAppleSymbolicHotKeys設定のうち、有効なstandard項目を読み込む。非公開の設定形式に依存し、設定IDで表示。実際の登録成功は未確認。
- アプリ独自のグローバルショートカット、Karabiner等の変換、隠れた操作、動的メニューの完全取得は未対応。
- メニュー取得はアプリごとにAX応答0.2秒、探索3秒・2500要素・深さ16を上限にする。同期AX呼出しの終了まで予算を超える場合がある。専用バックグラウンドTaskで処理する。

## 判定と表示

物理キーコードと修飾キーを正規化して比較。片方がMac全体、または同一アプリ内の場合に競合候補とする。別アプリ内だけの同じキーは候補にしない。同一アプリの文脈別操作や無効メニューを含むため、候補は競合の確定ではない。

キー表示の英字はUS配列の物理位置。その他の一部キーはKeyCode番号で表示する。現在の入力配列への変換は未対応。

初期表示は全取得結果。キー・アプリ・動作を検索でき、競合候補だけにも切替可能。取得日時とアプリ別の確認状況を表示。未確認を競合なしとは扱わない。

## 検証

ShortcutAuditTestsでアプリ間の非競合、全体キーとの候補、修飾キーの区別、同一アプリ内候補を検証。権限許可後の実機取得・実際の競合の再現は別途確認する。

## 表示サイズ

標準460×560pt、最小440×480pt。拡大／小さく戻すで1100×850ptへ切替。検索・候補切替・件数は上部、結果と確認状況はスクロール領域に配置。権限設定は鍵アイコン、取得範囲の説明はヘルプへ集約し、候補を断定しない旨は常時表示する。

## 有効状態

メニューのAXEnabledを読み、「メニューで有効」「今は無効」「状態未確認」を区別する。macOSの有効な設定は「設定で有効」とする。いずれも確認時点の情報で、アプリ内ショートカットはそのアプリ内で使用する。実際のキーの到達・横取り・独自グローバル登録の成功は断定しない。更新には再チェックを使う。
