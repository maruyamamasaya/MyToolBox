# 正規表現と小さな表のツール

## 入口と参照
「テキスト・CSV」に4つの独立windowを追加。共通3テーマ、検索、お気に入りに対応。
参照：[テスター](https://maruyamamasaya.github.io/tool/regex-tester/)、[ビルダー](https://maruyamamasaya.github.io/tool/regex-builder/)、[表](https://maruyamamasaya.github.io/tool/table-builder/)、[CSV統計](https://maruyamamasaya.github.io/tool/csv-statistics/)。

## 正規表現テスター
パターン・本文・置換文字列を入力すると180ms後にバックグラウンドで評価。一致部分のハイライト、全体と番号付きキャプチャ、UTF-16の位置・長さ、置換プレビュー、コピーを提供。g（全件／最初）、i、m、sに対応。空文字の一致は詳細欄に表示。

標準400×560の小窓で開始し、「拡大／小さく戻す」で1100×850と切り替える。入力を保ったまま一致箇所／キャプチャ／置換の結果タブを切替。g・i・m・sと制限の説明は設定ボタンに集約。ビルダー内のテスト欄も同じ小窓向け表示を使用。

ICUのNSRegularExpressionを使用。JavaScriptそのものの再現ではない。置換はICUテンプレート（$0・$1など、バックスラッシュでエスケープ）。既存StringReplacerのJS互換置換仕様は変更しない。入力64KiB、パターン・置換4KiB、一致1,000件、進捗コールバックで0.25秒、置換結果1MiBに制限。入力変更・画面破棄でキャンセルし古い結果を反映しない。

## 正規表現ビルダー
数字・英字・英数字・固定文字・空白／空白以外・任意・単語文字／単語文字以外・文字クラス・グループ・ORの12部品。追加、上下移動、削除、リセット、繰り返し（1回／任意／0回以上／1回以上／回数／範囲／最低回数）、先頭／末尾アンカー。
郵便番号・数字・英数字・簡易メール・簡易URL・簡易IPv4のプリセット。簡易IPv4は各要素の0〜255を保証しない。

標準400×600、拡大1100×850。「条件を編集／テスト」の2タブにまとめ、テスト本文・置換・フラグを保って切替。「条件を追加」と6プリセットはメニュー、各条件の移動・削除はアイコンボタン。生成パターンの手修正・コピーに対応。

生成パターンを同じ画面のテスターで確認・手修正・コピーできる。条件を変更すると手修正を含め再生成する。固定文字・OR・グループは内容を文字としてエスケープし、複数文字の繰り返しはまとまり全体へ適用。文字クラスは範囲などの正規表現構文を受け付ける。最大40条件、回数0〜1,000。

## 表ビルダー
標準1100×850の拡大版で開始し、小窓は420×600。「拡大／小さく戻す」で切替し、編集中のセルを確定して表の内容を維持。編集表・行列追加・出力形式・コピー／保存は常時表示。テキスト取り込みは専用ボタン、行列削除・見出し・文字揃えは設定に集約。

既存CSVGridを再利用。セルをダブルクリックで直接編集、行・列の追加・削除、CSV／TSV貼り付け取り込み、CSVファイルの直接読み込み、サンプル、クリア。最大100行・30列、取り込み512KiB。
1行目の見出し有無、左／中央／右揃え、Markdown／HTML／CSVを即時出力。コピー、明示操作でUTF-8のファイル保存。保存／読込は表自身のウィンドウに紐づくシートを表示し、現在のキーウィンドウに依存しない。保存直前にセル編集を確定する。CSV保存は再読込できる512KiB以内に制限。Markdownはパイプ・改行、HTMLは特殊文字、CSVは引用符などをエスケープする。

自動保存はしない。サンプル・取り込み・クリアで編集済み内容を置き換える場合は確認。閉じる前に必要な内容をコピー・保存する。CSV出力へ見出し設定・揃えは影響しない。

## CSV統計
標準400×600の小窓で列を選んで統計を確認。「拡大／小さく戻す」で1100×850へ切替し、拡大時は複数列の詳細を並べる。概要4項目・入力・コピーを常時表示し、見出し／タブ区切り／NULL指定は設定に集約。サイズ変更でも入力・設定・選択列を保持する。

CSVファイル（UTF-8／Shift_JIS）またはCSV／TSV貼り付け。入力後180msでバックグラウンド集計。1行目見出しの切替、NULL扱い文字列（カンマ区切り、初期NULL・N/A・NA）、クリア・サンプル・統計コピー。

最大512KiB・1,000データ行・30列。CSVDocumentの引用符／改行／BOM処理を共有し、短い行は空欄で補う。行数は見出しを除く。重複行はセル内容の完全一致で先頭以外を数える。

各列：型（空・数値・真偽値・文字列）、値数、NULL数／率、ユニーク数／率、最頻値。値の前後空白を除去し、NULL指定は大文字小文字を区別しない。ユニーク率の分母はNULL以外、NULL率の分母は全データ行。分母0は「—」。
数値はNULL以外がすべて有限のDoubleへ変換できる列のみ集計。合計・平均・中央値・最小・最大を表示。混在列は一部の数値だけを集計しない。数値0を欠損扱いしない。合計オーバーフローはエラー。金額等の厳密な十進数計算や大容量分析向けではない。
