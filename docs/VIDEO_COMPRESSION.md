# 動画圧縮

画像・デザインカテゴリの「動画圧縮」。複数選択またはファイルdropで最大200本を登録し、標準（1080pまで）／小さめ（720pまで）／最小（低画質）を選びMP4へ順番に変換する。macOS AVFoundationを使い、外部ツールや通信は不要。

保存先にUUID付きの新規フォルダを作成し、連番付きファイル名で保存する。元動画を変更しない。出力が元動画以上のサイズなら出力だけ削除し「縮小なし」と表示する。削減率は実ファイルサイズから計算する。映像なし・非対応・破損動画は理由を表示して次へ進む。

進捗はAVAssetExportSessionの値を使う。キャンセルは処理中の出力を削除し、完了済み出力を保持する。処理中は閉じる／終了を拒否し、キャンセル後に閉じられる。画質設定はOSのプリセットであり目標容量・コーデック・メタデータ保持を保証しない。HDR・字幕・複数音声などの保持は未保証。

検証：VideoCompressionTestsは保存先分離・同名衝突回避・元ファイル保護・取得失敗を確認。tools/VerifyVideoCompressor.swiftは合成MOVの実MP4圧縮・破損ファイル後の継続・重複除外・元動画保持・キャンセル・4テーマ非表示描画を確認する。素材と署名はFullおよびRenderToolIconsで確認。実ファイルパネル・drop・物理操作は別途確認。

## 表示サイズ

標準440×540pt（最小420×480pt）。拡大／小さく戻すで1100×850ptへ切替。動画一覧と結果を独立してスクロールし、選択・画質・開始／キャンセルと進捗は常時表示。元動画保持と形式の案内は常時表示し、詳細制限はヘルプに配置。変換・キャンセル・dropモデルは維持。
