## 参照と実装方針

ユーザー所有の [maruyamamasaya/tool](https://github.com/maruyamamasaya/tool) を浅いcloneで確認。参照revisionは `c011a4aa3518af8c72686ed3cf6950363b3612d7`（2026-10-15）。対象5ディレクトリのindex.html、app.js、test.jsを絞って読み、入力・計算・エラー・保存の挙動を確認した。参照cloneはbuild/reference/browser-tools（実行・製品同梱しない）。semantic indexは未提供、rgによるexact検索を利用。

ルートLICENSEは見つからずGitHub license metadataもnullのため、コード・画像を転用せずSwiftで独立実装した。Webサイトを埋め込む方式ではない。元版の機能とネイティブ版の差は以下に明示する。アプリ実行中の外部通信・依存パッケージはない。

## 祝日データ

[内閣府「国民の祝日」](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html) の [syukujitsu.csv](https://www8.cao.go.jp/chosei/shukujitsu/syukujitsu.csv) を2026-10-15に取得し、日付→名称のJSONへ変換。正本は [JapaneseHolidays.json](../Resources/JapaneseHolidays.json)、1,067日（1955〜2027年）。出典を明示し、推算式を用いない。土日に重なる祝日は土日として一度だけ計数。データ更新は開発時に手動で行い、対応年・テスト・同梱JSONを合わせて更新する。

## UIとライフサイクル

初期実装のツール一覧は2列カード（現在は下記の3列アイコンへ更新）、ツール別アクセント色。監視詳細は従来のpopover。新5本は独立したサイズ変更可能なNSWindowに表示し、外側クリックでは閉じない。同じツールの重複起動は既存windowを前面へ。ToolPage/ToolCardで見出し・背景・余白・操作位置を統一。CSVは空状態からファイル/貼付けを案内、表を主役にし、保存は右上。

追加の[テキスト3ツール](TEXT_TOOLS.md)と合わせ、一覧は幅440pt・高さ可変（11個で628pt、最大680pt）の3列アイコングリッドへ変更。共通SF Symbolsと色付き背景、ツール名で識別する。

### CSV実機試験（2026-10-15）

evidence/csv-ui/roundtrip-before-fix.csvは複数行セルを編集して保存、roundtrip-final.csvは表内セルをダブルクリックして「東京・表内編集済み」へ変更し、Tab/Returnを押さず保存。NSSavePanelで別名保存→NSOpenPanelで再読込→画面の値とファイルを照合し一致。日本語・カンマ・二重引用符・セル内改行とUTF-8 BOMを確認。結果は[final-result.json](../evidence/csv-ui/final-result.json)。

発見した不具合：貼り付け欄と編集欄の併用ではみ出す、選択再適用で表内編集のフォーカスが外れる。固定ヘッダー＋スクロール内容、選択差分適用＋明示ダブルクリックで修正。保存/ソート/行列変更前に編集を確定する。保存結果が8MiBを超えると再読込できないため、保存側にも同じ上限を追加。保存済みcloseで余分な未保存警告が出ないことも実機確認。
