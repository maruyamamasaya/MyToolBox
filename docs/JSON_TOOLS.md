# JSONツール

一覧の「テキスト・CSV」→「JSONツール」で起動。共有入力を保持して3モードを切り替える。ローカル処理のみで、自動保存・外部送信は行わない。

- 構造ビュー：object／arrayの展開・折りたたみ、型・直下の要素数、選択値のコピー、JSON Pointerのコピー。ルートのPointerは空文字。キー内の `~` と `/` はRFC 6901形式でエスケープする。
- 整形：2／4スペース・圧縮、結果コピー、共有入力への適用。objectのキー順と数値トークンを保持し、大整数・指数・小数を浮動小数点に変換しない。
- ビルダー：空入力からobject／arrayを開始。ツリーで選択したコンテナへ6種類の値を追加、スカラー値変更、ルート以外の部分木削除。文字列は引用符不要、booleanはtrue／false。キー名変更・コンテナ全体の置換は共有入力で行う。

## ファイルの読み込み・保存

JSONファイル1つを画面（共有入力欄も可）へドロップ、または「JSONを開く…」で読み込む。UTF-8（BOM付きも可）・通常ファイルのみ。内容を検証してから共有入力を置換し、不正JSON・文字コードエラー・容量超過・読込失敗では現在の入力を保持する。

「JSONを保存…」で共有JSON入力をUTF-8・BOMなしで保存する。整形モードの結果を保存する場合は「入力に適用」してから保存。保存先は毎回選択し、同名ファイルはOSの置換確認に従う。保存前に現在の入力を再検証し、成功時だけ保存済みにする。書込みはatomic。保存キャンセル・失敗では入力と未保存状態を保持する。

未保存の入力がある場合、別ファイルの読み込み・window閉鎖・アプリ終了時に破棄確認を表示する。ファイル処理中は編集・二重操作・window閉鎖を止める。自動保存はしない。

入力は256 KiB・48階層・4,000要素まで。重複キー・末尾カンマ・不正エスケープ・不正数値はエラー。構文エラーは行・列を表示。入力変更後は180ms待って専用actorで解析し、古い解析結果を破棄する。無効な入力から旧ツリーを編集・コピーすることはできない。サンプルボタンは入力を書き換える。

## 検証

`JSONWorkspaceTests`で正確な数値・Unicode・スカラー・整形往復・CRLF・構文エラー位置・各上限・部分木編集を検証。`tools/RenderJSONWorkspace.swift`はモデルの追加・変更・削除・Pointer・エラー復帰と3モード×3テーマの合成描画を確認する。

実機では一覧から起動し、貼り付け→3モード切替→折りたたみ・選択→追加・編集・削除→整形適用→コピーを確認する。合成描画と実機操作は区別してsessionsに記録する。

ファイル検証：単体でUTF-8/BOM・別名／同名保存・元ファイル保持・不正入力で既存保存先保持・容量超過・ディレクトリ・不存在・保存先失敗を確認。モデルで読込後の未保存状態・保存基準・失敗時のファイル関連付け保持を確認。実機では読込・編集・保存キャンセル・閉じるキャンセル・別名保存と実ファイル一致を確認。
