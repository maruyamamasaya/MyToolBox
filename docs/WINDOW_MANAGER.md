# ウィンドウマネージャー

ツール一覧の「システム・音声」から起動。直前に使っていた外部アプリの選択中ウィンドウを配置する。対象アプリ名を画面に表示する。MyToolBox自身は対象外。

## 操作

初回は「許可を要求」を押し、「システム設定を開く」から独立版「ウィンドウマネージャー」のアクセシビリティをユーザーが許可し、「許可を再確認」を押す。一覧に出ない場合は「許可対象をFinderで表示」で表示したアプリを設定の＋から追加する。本体MyToolBoxへの許可とは別。アプリから許可を自動変更しない。更新後に許可が繰り返し必要になる場合の署名設定は[署名運用](CODE_SIGNING.md)を参照。対象アプリのウィンドウを選んでからMyToolBoxへ戻り、配置ボタンを押す。

左右・上下半分、左／中央／右1/3、左右2/3、四隅1/4、中央、最大化、復元の16操作。最大化はDock・メニューバーを避けた領域へのサイズ変更で、macOSのフルスクリーンではない。

「グローバルショートカット」は初期OFF。ON/OFFをUserDefaultsの`tools.windowManager.shortcuts.v1`へ保存。ONなら再起動時も登録する。すべてControl＋Optionと次のキーを使用する。割り当ての個別編集は未対応。競合時は登録を全部解除し、理由を表示する。

| キー | 配置 |
| --- | --- |
| ← / → / ↑ / ↓ | 左 / 右 / 上 / 下半分 |
| 1 / 2 / 3 | 左 / 中央 / 右1/3 |
| 4 / 5 | 左 / 右2/3 |
| Q / W / A / S | 左上 / 右上 / 左下 / 右下1/4 |
| C | 中央 |
| Return | 最大化 |
| Delete | 復元 |

ショートカットはCarbonのホットキー登録で、通常の文字入力を収集・記録しない。Q/W/A/S/C/数字は物理キー位置に対応。画面を閉じてもONの間は動作する。

## 制限

Accessibility APIで選択中ウィンドウの位置とサイズだけを操作する。現在ウィンドウとの重なりが最大の画面を使用。フルスクリーン、固定サイズ、API非対応、権限不足は理由を表示。アプリの最小サイズなどで一致しない場合は成功扱いにしない。操作途中の失敗では一部変更の可能性を案内する。

復元は最初の配置直前の位置をウィンドウごとに最大100件メモリ保持し、復元成功時に削除。アプリ終了で消去。外部アプリ終了・画面構成変更後の復元は保証しない。外部送信・タイトル／本文の保存・他アプリの設定変更は行わない。

## 検証

WindowLayoutTestsで負の画面座標・上下の画面・端数幅の隙間・中央のサイズ制限を検証。権限許可後の外部アプリ実操作とホットキー競合・複数画面は手動確認が必要。自動ビルド成功は実機操作の成功を意味しない。

API：[Apple AXUIElementSetAttributeValue](https://developer.apple.com/documentation/applicationservices/1460434-axuielementsetattributevalue)、[AXIsProcessTrusted](https://developer.apple.com/documentation/applicationservices/1460720-axisprocesstrusted)。

## 独立常駐

同梱の独立版「ウィンドウマネージャー」がショートカット・対象アプリ・復元位置を保持する。本体は16キーを登録せず、保存済みの有効設定がONでhelperがいないときだけ、画面を表示せず起動する。helperが既にいる場合は再起動した本体から触らない。有効中に×で画面を閉じてもhelperは常駐し、一覧から再選択すると画面を再表示する。OFFにして閉じた場合は終了する。helper自身をメニュー／⌘Qで明示終了するとキーは停止し、有効設定は保持して次の本体起動時に復元する。

保存先は既存local.MyToolBox／tools.windowManager.shortcuts.v1を継承。競合時は部分登録を含めて全解除し、ON設定を消さず理由を表示する。設定ONと実登録結果は別に扱う。親と他のMyToolBox helperも配置対象から除外する。

独立版は親と異なるbundle IDのため、親へのアクセシビリティ許可を前提にしない。独立版「ウィンドウマネージャー」の許可はユーザーが確認する。同じ証明書でhelperを署名するが、実機のTCC許可維持は署名検証と別。許可・署名・ログイン設定をアプリや検証が自動変更することはない。[設計](../decisions/0012-window-manager-service.md)・[検証記録](../sessions/2026-10-20-independent-window-manager.md)。配置・最新版切替済み。許可済み表示と代表キーの左半分／復元を[利用者が実入力確認](../sessions/2026-10-20-helper-latest-shortcuts.md)。

## 更新後の操作不能を防ぐ

デプロイ前に本体とhelperを通常終了し、新版配置後に起動する。常駐したままバンドルを交換して旧実行ファイルを削除する更新は行わない。許可スイッチやキー登録成功だけでは配置成功を示さない。[必須デプロイ手順](../OPERATIONS.md#デプロイの必須手順)を参照。

## 表示サイズ

標準460×620pt（最小440×540pt）。拡大／小さく戻すで1100×850ptへ切替。16配置は4列の図入りボタン、対象・ショートカットON/OFFを上部、許可操作は折りたたみ内へ配置。許可の再確認は対象横の更新ボタン。配置・登録・復元モデルは維持。
