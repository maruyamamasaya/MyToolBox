# ウィンドウマネージャー

ツール一覧の「システム・音声」から起動。直前に使っていた外部アプリの選択中ウィンドウを配置する。対象アプリ名を画面に表示する。MyToolBox自身は対象外。

## 操作

初回は「システム設定を開く」からMyToolBoxのアクセシビリティをユーザーが許可し、「許可を再確認」を押す。アプリから許可を自動変更しない。対象アプリのウィンドウを選んでからMyToolBoxへ戻り、配置ボタンを押す。

左右・上下半分、左／中央／右1/3、左右2/3、四隅1/4、中央、最大化、復元の16操作。最大化はDock・メニューバーを避けた領域へのサイズ変更で、macOSのフルスクリーンではない。

「グローバルショートカット」は初期OFF。ON/OFFをUserDefaultsの`tools.windowManager.shortcuts.v1`へ保存。ONなら再起動時も登録する。すべてControl＋Optionと次のキーを使用する。割り当ての個別編集は未対応。競合時は登録を全部解除し、理由を表示する。

| キー | 配置 |
| --- | --- |
| ← / → / ↑ / ↓ | 左 / 右 / 上 / 下半分 |
| 1 / 2 / 3 | 左 / 中央 / 右1/3 |
| 4 / 5 | 左 / 右2/3 |
| Q / W / A / S | 左上 / 右上 / 左下 / 右下1/4 |
| C | 中央 |
| Return | 最大化 |
| Delete | 復元 |

ショートカットはCarbonのホットキー登録で、通常の文字入力を収集・記録しない。Q/W/A/S/C/数字は物理キー位置に対応。画面を閉じてもONの間は動作する。

## 制限

Accessibility APIで選択中ウィンドウの位置とサイズだけを操作する。現在ウィンドウとの重なりが最大の画面を使用。フルスクリーン、固定サイズ、API非対応、権限不足は理由を表示。アプリの最小サイズなどで一致しない場合は成功扱いにしない。操作途中の失敗では一部変更の可能性を案内する。

復元は最初の配置直前の位置をウィンドウごとに最大100件メモリ保持し、復元成功時に削除。アプリ終了で消去。外部アプリ終了・画面構成変更後の復元は保証しない。外部送信・タイトル／本文の保存・他アプリの設定変更は行わない。

## 検証

WindowLayoutTestsで負の画面座標・上下の画面・端数幅の隙間・中央のサイズ制限を検証。権限許可後の外部アプリ実操作とホットキー競合・複数画面は手動確認が必要。自動ビルド成功は実機操作の成功を意味しない。

API：[Apple AXUIElementSetAttributeValue](https://developer.apple.com/documentation/applicationservices/1460434-axuielementsetattributevalue)、[AXIsProcessTrusted](https://developer.apple.com/documentation/applicationservices/1460720-axisprocesstrusted)。
