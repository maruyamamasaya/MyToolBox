# ログハイライター

参照：[Web版](https://maruyamamasaya.github.io/tool/log-highlighter/)。ネットワーク・サーバーカテゴリから独立画面を開く。

- ログを貼り付けて「ログ解析」。入力上限2 MB、画面を閉じると破棄。ファイル保存・外部送信は行わない。
- FATAL／CRITICAL、ERROR、WARN／WARNING、INFO、DEBUG、TRACEを大文字小文字を区別せず単語境界で判定。複数含む行は重大度順、未検出はOTHER。
- 元の行番号・空行を保持。レベル別件数、ERRORのみ（FATAL含む）、WARN以上、個別チェック、全表示に対応。
- 前後0／1／3／5／10行を追加。重複行は一度だけ表示。コピー対象は表示中の行の本文（改行はLF）。
- 検索は正規表現を使用しない文字列一致。表示中の一致数・前後移動・現在一致の強調、長い行の折り返し。
- 独自キーワードは各100文字・最大10個、大小文字を無視して重複を禁止。削除可能。
- 共通3テーマを使用。Web版の自動解析は明示ボタンに変更し、入力中の全行再解析を避ける。
