# メニューバーの通信幅・天気余白・RAMアイコン

## Request / Investigation
通信量の小数点によるメニュー位置の移動、天気の左右余白、RAMアイコンの形状を調整。
通信セルは幅を予約していたが、左端の余白削除が現在の文字幅に依存していた。

## Changes / Files Changed
- StatusStrip.swift：通信セルの左端トリミングを停止。99.9MB/sまでの予約幅は維持し、追加3ptを削除。これを超える桁数は欠けないよう拡張する。
- RainRadar.swift：天気アイコン左を3→1pt、数値右を2ptへ。23.4°C／65%の例で67→55pt。
- StatusStrip.swift：RAMのチップを等間隔の塗り形状にし、接点を基板へ接続。アイコンの占有幅は維持。
- RenderStatusStrip.swift：小数点・単位境界8値×2サイズ×3配置の幅不変チェックを追加。

- 天気の右隣に「降水確率／値」の2段列を追加。直近の有効時間枠を使用し、対象時刻はtooltipへ。欠測は—。代表合成値の全幅93pt。

## Validation / Result
Fast成功。通信幅48条件と実Viewのオフスクリーン描画成功。
天気は本番クラスを抽出して合成値で非表示描画し、55ptへの縮小を確認。
検証器8件成功。Fullはsandboxの証明書アクセスで一度失敗後、通常署名環境で成功。

メモリアイコンと降水確率の追加後にもFullを再実行。
