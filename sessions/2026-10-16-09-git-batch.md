# Git一括管理

## Request
Developmentに置かれた4本のスクリプトをMyToolBoxの画面へ統合する。

## Investigation
元スクリプトは直下リポジトリのfetch／チェック、ff更新、全変更のcommit／push。既存作業ツリーにセキュリティ・ウィンドウ配置の変更があり、そのまま保持。

## Changes / Files Changed
GitBatch.swiftに通常ユーザーのGitを引数配列で直列実行するworker、GitBatchView.swiftにフォルダ選択・選択対象・変更表示・確認付き操作を実装。ToolCatalog／ToolWindows／ToolLauncherへ登録。共通ToolPageに明示通信のラベルを追加。詳細は[仕様](../docs/GIT_BATCH.md)。元スクリプト変更なし。

## Validation
Fast成功、単体152件成功。ローカルbare origin・2cloneでコミット送信・先行停止・ff更新・dirty停止・Detached HEAD・メッセージ文字非実行を確認。初回のテスト比較はmacOS一時パスの/varと/private/var表記差で失敗し、対象件数と名前の検証に修正。Python検証器5件成功。Full・Releaseビルド・署名検証成功。RenderGitBatchで3テーマの合成データ描画を確認（実機クリック検証とは区別）。

## Result / Remaining Issues
ユーザーの実リポジトリへの送信なし。ユーザーの追加依頼で/Applicationsへ配置。アプリメニューの確認付き終了→入替→再起動。署名・全ファイルSHA-256一致を確認後、一時旧版を削除。実画面で52 TOOLS／ネットワーク・サーバー10件を確認。検索入力が反映されず、その後CUAのtimeout／noWindowsAvailableが継続したため、Git個別画面の実操作は未確認。認証は既存Git・SSH設定を使用し、対話認証はエラーになる。タイムアウト時の部分反映・子プロセスの制約は仕様に記載。
